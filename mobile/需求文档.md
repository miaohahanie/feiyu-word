## 1. 背景与目标

桌面端「单词桌宠」目前只能在电脑上查词、复习。用户希望：

> 把电脑上的单词与复习进度同步到手机，手机能在合适的时间提醒我复习，并且就算不在电脑前也能完成复习。

手机端的目标是成为桌面端的**复习伴侣**，而不是完整副本：第一版只做「同步 + 复习 + 提醒」闭环，不做查词、词本管理、导入导出等重功能。

## 3. 用户故事（核心场景）

### 场景一：首次配对
用户打开手机 App，**扫描电脑上显示的二维码**（二维码内含 IP/端口/配对信息；也可手动输入 IP + 6 位配对码）；
配对成功后，手机选择要同步的词本（如「六级词汇 · 内置」），点击同步。

### 场景二：日常同步
- 电脑端开着「单词桌宠」；
- 手机与电脑在同一 WiFi；
- 手机端「下拉/点击同步」，拉取最新单词、释义、复习状态；
- 同步完成后，手机本地保存，之后**断网也可以复习**。

### 场景三：手机复习
- 到词条的到期时间（**随时提醒**），手机弹出本地通知：「有 N 个词到期，来复习一下吧」；
- 用户点开 App，逐词复习：
  1. 显示单词（可先显示音标/例句，可选）；
  2. 点击「显示答案」看到中文释义；
  3. 按「认识 / 模糊 / 不认识」快速自评；
  4. 自动进入下一个词；
- 复习完当天队列后，展示总结（今日复习数、连续天数等，可选）。

### 场景四：进度回传
- 手机下一次与电脑同步时，把手机的**复习结果/自评/复习次数**上传；
- 电脑端更新对应词的 `nextReview`、`interval`、`ease`、`mastered`、统计/打卡；
- 两端保持一致的复习曲线。

## 4. MVP 功能范围

### 4.1 包含（第一版必须做）

1. **配对与安全**
   - 手机通过局域网连接电脑端同步服务；
   - **二维码扫码配对**：电脑端显示二维码（内含 IP/端口/6 位配对码），手机扫码自动连接；
   - 同时保留**手动输入 IP + 6 位配对码**作为备用方式；
   - 仅在局域网内可用，不需要公网/服务器。

2. **词本选择**
   - 同步时展示电脑端词本列表；
   - 手机端可选择要同步的词本（至少支持：CET4、CET6、自定义词本）；
   - 支持切换词本后重新同步。

3. **数据同步（双向）**
   - 下行（电脑 → 手机）：
     - 单词、中文释义、音标；
     - 例句（原文 + 译文，如有）；
     - 复习状态：`reps`、`interval`、`ease`、`lapses`、`nextReview`、`mastered`。
   - 上行（手机 → 电脑）：
     - 手机端的复习结果（自评分、复习时间、是否标记已掌握）；
     - 手机端产生的复习记录 / 进度更新。

4. **离线复习**
   - 同步后的数据保存在手机本地数据库（SQLite）；
   - 手机断网/电脑关机时，仍可正常复习；
   - 手机端不依赖电脑端实时在线。

5. **复习交互（轻量）**
   - 每张卡：英文单词 → **显示音标** →（如有）**显示例句/译文** → 点「显示答案」→ 中文释义；
   - 快速自评按钮：
     - 「不认识」→ 对应自评分低（建议映射为 1）；
     - 「模糊」→ 对应自评分中（建议映射为 4）；
     - 「认识」→ 对应自评分高（建议映射为 8）；
   - 按钮文案/映射可在设置中调整（可选，非 MVP 必须）；
   - 支持「跳过」：30 分钟后再次出现（与电脑端行为一致）。

6. **提醒（随时提醒）**
   - 手机端根据同步来的 `nextReview`，按到期时间**随时提醒**，不限定固定时段；
   - 同一时间到期的多个词**合并成一条通知**，避免轰炸，内容如：「有 N 个词到期，来复习一下吧」；
   - 点通知打开 App 进入复习页；
   - 复习完/重新同步后，更新或取消未到期的提醒；
   - 提醒在 App 未打开/杀后台时也能弹出（Android 本地通知 + WorkManager/精确闹钟）；
   - 遵循 Android 精确闹钟权限与系统省电策略，允许少量延迟；支持通知预览开关（默认不展示词条内容，保护隐私）。

### 4.2 不包含（后续再做）

- 手机端查词、添加新词；
- 手机端新建/删除/导入/导出词本；
- 例句自动抓取/剪贴板功能；
- 云同步、账号系统；
- iOS 版本（架构上预留，不实现）。

## 6. 技术方案建议

> 用户未指定技术栈，由开发方建议如下：

### 6.1 推荐：Flutter（Dart）

- **理由**：
  - 未来若想上 iOS，可复用大部分代码；
  - 一套代码适配 Android 各版本，UI 开发效率高；
  - 本地数据库（`sqflite`/`drift`）、HTTP（`dio`）、本地通知（`flutter_local_notifications`）、后台任务（`workmanager`）生态成熟；
  - 适合 APK 快速交付。
- **备选**：原生 Android（Kotlin + Jetpack Compose）——系统集成/后台更原生，但只有 Android，之后做 iOS 需重写。
- **结论**：**建议采用 Flutter**，最低支持 Android 8.0（API 26）及以上。

### 6.2 桌面端同步服务（集成到现有 Electron）

- **已确认**：不做独立 PC 工具，直接集成到现有 Electron 主进程（`main.js`）；
- 用 Node 内置 `http`/`net` 起一个局域网 HTTP 服务；
- 端口建议固定（如 `8787`，可配置）；
- 手机端通过 `http://<电脑局域网IP>:8787` 访问；
- 电脑端新增「手机同步」设置页，显示：
  - 当前局域网 IP + 端口；
  - **二维码**（内容：`http://<IP>:<PORT>?code=<6位配对码>`，手机扫码即可配对）；
  - 6 位配对码（每次启动/刷新可重新生成，手动输入备用）；
  - 已配对设备列表；
  - 同步日志（可选）。

### 6.3 同步接口（草案）

```
POST /api/pair              # 手机注册设备，扫码或输入 6 位配对码，获得 deviceId
GET  /api/books             # 获取词本列表（id/name/count）
GET  /api/sync?book=<id>&since=<cursor>   # 拉取词条与进度增量
POST /api/sync              # 上传手机端的复习结果
POST /api/ack               # 确认已收到（可选）
```

- 数据格式：JSON；
- 同步粒度：按词本 + 更新时间游标做增量；
- 冲突处理（草案）：
  - 同一词复习进度的简单冲突采用「**最后更新时间胜出**」；
  - 复习历史采用「**事件去重合并**」（按事件 ID），两端都不会丢记录；
  - 后续可升级为更精细的合并策略。

## 7. 数据模型（草案）

手机本地数据库与桌面端数据字段保持一致，便于双向同步：

```json
{
  "bookId": "book-cet6",
  "bookName": "六级词汇 · 内置",
  "word": "abandon",
  "meaning": "v. 放弃, 抛弃, 遗弃…",
  "phonetic": "/ə'bændən/",
  "examples": [
    { "text": "...", "translation": "...", "source": "剪贴板" }
  ],
  "reps": 3,
  "ease": 2.5,
  "interval": 6,
  "lapses": 0,
  "lastRating": 8,
  "nextReview": "2026-09-03T20:00:00+08:00",
  "mastered": false,
  "history": [
    { "id": "evt-xxx", "date": "2026-09-01T12:00:00+08:00", "rating": 8 }
  ],
  "updatedAt": "2026-09-01T12:00:00+08:00"
}
```

- 手机端只允许修改：复习相关字段（`reps/ease/interval/lapses/nextReview/mastered/history/updatedAt`）与例句状态；
- 手机端不产生新词条（MVP 范围外）。

## 8. 非功能需求

| 类别 | 要求 |
| --- | --- |
| 离线 | 同步后完全离线可用；本地数据库持久化 |
| 通知 | 支持系统本地通知；App 被杀死后仍能提醒；按 `nextReview` 调度“随时提醒”；遵循系统勿扰/省电策略，允许少量延迟 |
| 性能 | 同步 3000～6000 词目标在局域网内 10 秒内完成（增量同步优先） |
| 安全 | 仅监听局域网；6 位配对码；不上传到公网；不收集账号信息 |
| 隐私 | 手机本地仅保存学习数据；无账户、无云上报 |
| 兼容 | Android 8.0+；支持横竖屏自适应（MVP 可仅竖屏） |
| 稳定性 | 同步失败不破坏本地数据；支持重试；显示错误原因 |

## 9. MVP 验收标准

1. 电脑与手机在同一 WiFi 下，手机**扫码**（或手动输入 IP + 6 位配对码）完成配对；
2. 手机可选择并同步一个词本（内置 CET4/CET6 或自定义），同步后**断网**仍能看到单词和复习状态；
3. 手机可完成轻量复习（认识/模糊/不认识），并计算下次复习时间；
4. 手机端按到期时间**随时提醒**，同时到期词合并为一条通知；App 未打开也能收到；
5. 再次联网同步后，手机端复习进度回传电脑，电脑端 `reviewed`、`nextReview`、`mastered` 等状态更新；
6. 手机端可切换同步词本；
7. 同步失败/断网能提示且不影响本地已复习数据。
