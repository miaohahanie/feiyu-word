# 手机端（规划中）

本目录用于存放手机端（Android / 后续可能 iOS）相关的需求、设计与代码。

当前状态：**需求已确认（v0.2），技术设计文档 v0.1 已完成**。

- 目标：把电脑端「单词桌宠」的单词与复习进度同步到手机（局域网），并在手机上按到期时间**随时提醒**、离线完成复习。
- 需求文档：[需求文档.md](需求文档.md)（v0.2）
- 技术设计：[技术设计文档.md](技术设计文档.md)（v0.1）
- 技术方向：Android 优先，建议 Flutter；局域网直连 + 双向同步；MVP 只做「同步 + 复习 + 提醒」。
- 已确认：二维码扫码配对（手动 IP+配对码备用）、同步服务集成进现有 Electron、冲突用「最后更新时间胜出 + 历史合并」、Android 8.0+、复习显示音标/例句/译文、提醒为「随时提醒」。
- 下一步：从 M1（电脑端同步服务 + 设置页）开始实现。
